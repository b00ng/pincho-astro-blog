PINCHO RESTAURANT MENU — STATIC WEBSITE

Upload the entire contents of this folder to your website document root.
Keep the folder structure unchanged:

  index.html       A La Carte menu
  brunch.html      Set / Brunch menu
  assets/style.css
  assets/favicon.svg
  assets/images/*.jpg

No build process, database, Node.js, or third-party service is required.

Typical hosting:
- cPanel: upload the contents to public_html.
- Apache/Nginx: upload the contents to the configured document root.
- S3/static hosting: upload every file and use index.html as the index document.

The menus use relative paths and may also be hosted inside a subfolder.
The shared top navigation links between index.html and brunch.html.
